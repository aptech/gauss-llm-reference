# Historical Planning Archive

This directory is the non-executable delivery record for the `gauss-doc-qa`
Python tool. Milestones v1.0, v1.1, and v1.2 were completed by 2026-03-15.

Nothing here is a current task queue, resumable session, agent command, or
auto-chain configuration. Do not run historical `/gsd:*` commands, continue a
phase, regenerate old plans, or treat verifier/persona attributions as current
agent routing.

The phase `RESEARCH.md`, `VALIDATION.md`, `VERIFICATION.md`, plan, summary,
milestone, roadmap, requirements, retrospective, and project files remain as
dated provenance for the shipped work. Their historical command names and
agent attributions are preserved intentionally.

`STATE.md` is the final completion snapshot. The former active-shaped
`config.json` was retired after completion and remains available in Git
history. New work requires a new, explicitly approved plan based on current
repository state; it must not resume this archive.
